---
name: incremental-implementation
description: "Выполнить очередной небольшой законченный шаг и проверить контракт перед продолжением."
---

Делай один законченный шаг за раз: реализовать → проверить → передать результат.
Сохраняй работу предыдущих шагов, существующие соглашения и платформенные границы.
Не смешивай задачу с соседним рефакторингом и новыми зависимостями. После изменения
проверяй затронутый контракт; на последнем шаге — все критерии и проверки проекта.
Уже успешную проверку неизменившегося кода не повторяй без новой причины.
В Execution Loop коммит делает runner после независимого ревью. Передай handoff
с файлами, решениями, рисками и фактическими command/result, сохрани первый сбой.
Feature flags, миграции и инфраструктуру вводи только при необходимости задачи.

Адаптация Addy Osmani Agent Skills, MIT; источник и версия — `docs/ai-agent/execution-loop/upstream-skills.json`. Правила Cosplay 2 имеют приоритет.
Подробные примеры: [справочник](references/upstream-reference.md), только по необходимости.
