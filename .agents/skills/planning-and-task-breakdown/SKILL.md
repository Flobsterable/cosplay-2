Прочитай требования, текущий код и аналогичный сценарий; работай read-only.
Определи зависимости до порядка реализации. Разбивай по законченным контрактам,
а не по слоям сразу всего проекта. Каждый шаг должен иметь наблюдаемый результат,
критерий приёмки, предметные навыки и способ проверки. Большой независимый сценарий
раздели ещё раз; не создавай новые требования.
В Execution Loop верни JSON плана, запись и очередь ведёт runner. Укажи предыдущие
задачи, чьи результаты нужны, включая EL-ID из требований. Последний шаг проверяет
всю задачу и затронутые docs. Вне loop соблюдай явно разрешённый scope.
