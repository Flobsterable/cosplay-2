# Festival UI

- Screen/компоненты получают модели, состояние и callbacks. Не добавляй запросы API сюда.
- Сохраняй год, сброс месяца, поиск/категорию по загруженному каталогу и семантику
  «Актуальные». Избранное должно оставаться доступным без повторного запроса деталей.
- Loading/Error/Success и пустой список отображаются явно. Для новых повторно
  используемых компонентов принимай Modifier и применяй его к корню.
- Используй MaterialTheme и существующие компоненты, задавай contentDescription
  интерактивным иконкам. Не добавляй зависимости для простой функции UI.
- Проверки: Android/Desktop compilation, composeApp desktopTest и lintDebug;
  для новой логики добавляй содержательные тесты в существующую тестовую конфигурацию.
