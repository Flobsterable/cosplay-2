# Конфигурация AI-агента v2

Статус на 24 октября 2026 года: подготовка второй версии инструкций.
Второй эксперимент не запускался; результатов генерации и проверок приложения
для v2 пока нет. Изменения правил не означают выполненный рефакторинг приложения.

## Отличия от v1

- Пользовательские строки выносятся в общие строковые ресурсы Android/Desktop.
- Экраны декомпозируются; компоненты размещаются в подпапках по ответственности.
- Бизнес-сценарии оформляются как use cases; UI-состояние остаётся у его владельца.
- Определены границы core и условия выделения core/ui с общей дизайн-системой.
- Добавлены требования к совместимости сохранённых данных, повторным действиям,
  устаревшим результатам, доступности, спискам Compose и регрессионным тестам.
- Фактическая архитектура отделена от целевых соглашений. Подробные правила
  распределены по вложенным AGENTS.md, примеры вынесены в отдельный справочник.

Исходная конфигурация и результаты v1 находятся в соседней папке `../v1/`;
при подготовке v2 они не изменяются.

## До запуска второго эксперимента

Для отдельного эксперимента на длительность автономной работы подготовлен
[Execution Loop](../execution-loop/README.md): текущий пул из 15 мини-задач в Notion,
последовательный runner Codex CLI, коммиты после проверок, отдельные draft PR
в линейной цепочке и журнал времени в минутах. Локальный пример содержит 18 задач.
Это не результат запуска v2; измеряемые прогоны ещё не выполнены.

1. Завершить согласование правил и сохранить отдельный снимок конфигурации v2:
   корневые/вложенные инструкции, repo skills и конфигурации ролей.
2. Зафиксировать исходное состояние кода, задачу, модель и параметры запуска,
   а также различия окружения относительно v1. Обновления сборки между запусками
   учитывать отдельно от влияния инструкций.
3. Выполнить эксперимент по согласованной задаче; сохранить исходный результат,
   diff, фактические проверки и ограничения в этой папке. Не перезаписывать v1.

Снимок конфигурации, задача и запуск пока не зафиксированы. Этот документ
описывает подготовку, а не подтверждает выполнение перечисленных шагов.
