- Отвечай на языке текущего запроса, кратко объясняй результат и ограничения проверок.
- Определяй стек по исходникам и сборке. Архитектура, структура папок, naming и версии

  для изменяемых файлов. Не навязывай KMP другим проектам.

  результат от пропущенной проверки или ошибки окружения; не выдумывай результаты.
