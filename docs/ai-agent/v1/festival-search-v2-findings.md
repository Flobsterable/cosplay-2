# FestivalSearch v1: замечания для сравнения с v2

Подтверждённых дефектов реализации по независимому статическому ревью нет.
Исправления после первого результата проверки не вносились.

Проверки сборки, тестов и Android Lint заблокированы окружением: проект требует
JDK 17, локально найденный Android Studio JBR имеет версию 21.0.10; другой
локальный JDK 17 не найден. Тесты не запустились (0 выполнено). Исходный запуск
Lint также не видел Android SDK; повтор с установленным для процесса
`ANDROID_HOME` прошёл поиск SDK и остановился на отсутствии JDK 17.
После предоставления JDK 17 нужно повторить команды из
`festival-search-verify-report.md` и сравнить результаты с этой версией.

Вне изменения: в нижней части `docs/feature-flows.md` уже было устаревшее
описание навигации. Это не дефект `FestivalSearch`.
