# FestivalSearch v1: замечания для сравнения с v2

Документ объединяет ранние ограничения и последующие результаты первой генерации.
Название файла историческое; повторная генерация v2 не выполнялась.

Подтверждённых дефектов реализации по независимому статическому ревью не было.
Архивные исходники и тесты в source/ после первого результата не исправлялись.

Первоначальные проверки сборки, тестов и Android Lint были заблокированы: проект требовал
JDK 17, локально найденный Android Studio JBR имеет версию 21.0.10; другой
локальный JDK 17 не найден. Тесты не запустились (0 выполнено). Исходный запуск
Lint также не видел Android SDK; повтор с установленным для процесса
`ANDROID_HOME` прошёл поиск SDK и остановился на отсутствии JDK 17.
После предоставления JDK 17 обе компиляции прошли; composeApp выполнил 34 теста,
три из которых упали в FestivalSearchTest. Отрицательные примеры «Томск» содержат
подстроку «омск», поэтому ожидания противоречат реализации поиска подстрок.
Первое статическое ревью этого не заметило. Android Lint оставался заблокирован
HTTP 403 Maven Central. Логи и коды — environment-ready-results.json.

Впоследствии рабочие тесты исправлены отдельно: отрицательные примеры заменены на
«Казань», добавлен седьмой тест, явно проверяющий подстроки. Реализация и архив v1
сохранены. См. ../../build-upgrade/TOOLCHAIN-FIX.md. Актуальный аудит — ../AUDIT.md;
первоначальные падения не являются дефектами текущих рабочих тестов.

Вне изменения: в нижней части `docs/feature-flows.md` уже было устаревшее
описание навигации. Это не дефект `FestivalSearch`.
