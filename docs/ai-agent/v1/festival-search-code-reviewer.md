# FestivalSearch: независимое ревью v1

Роль: настроенный `code-reviewer`. Проверены `FestivalSearch.kt`,
`FestivalSearchTest.kt`, изменение `docs/feature-flows.md`, применимые
`AGENTS.md`, skills и `docs/review-rules.md`. Новые Kotlin-файлы не отслеживаются
Git и поэтому прочитаны напрямую, а не только через `git diff`.

## Результат

Подтверждённых дефектов и существенных рисков в изменении не найдено.
Сервис использует доступные Android и Desktop Kotlin API и модель из
`core/model`. Для всех слов действует AND, для `title` и `city` — OR;
`Char.isWhitespace()` обрабатывает пробельные символы, `filter`/`toList`
сохраняют порядок и не меняют входной список. Тесты охватывают кириллицу,
смешанные поля, Unicode-пробел, пустой запрос и данные, отсутствие совпадений,
порядок и неизменность входа. Документ отделяет новый сервис от существующего
поиска в UI. UI-интеграция по задаче не требуется.

Изменения не затрагивают suspend-операции, ресурсы, UiState, навигацию и сеть.
Это ревью по исходникам: компиляция и тесты в его рамках не запускались.

Отдельное наблюдение вне diff: в нижней части `docs/feature-flows.md` уже было
устаревшее описание навигации; это не дефект нового сервиса и не исправлялось
в замороженной версии v1.
